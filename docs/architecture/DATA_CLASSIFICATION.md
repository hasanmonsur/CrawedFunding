# Data Classification

| Classification | Examples | Controls |
|---|---|---|
| Public | Published project summary | Integrity review and versioning |
| Internal | Configuration, templates | Authenticated access |
| Confidential | Sponsor documents, contracts | Role-based access and export audit |
| Restricted Identity | NID/passport, KYC, photo, beneficial owners | Encryption, masking, retention, no logs |
| Restricted Financial | Bank accounts, payments, ledgers, distributions | Encryption, masking, reconciliation, immutable audit |
