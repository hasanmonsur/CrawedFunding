# Domain Glossary

| Term | Meaning |
|---|---|
| Organization | Tenant or operating institution using CrowdFund360. |
| Project | Independent investment or administration unit with its own plans, ledgers, reports, risks, documents, and lifecycle. |
| Sponsor | Person or business responsible for proposing and operating a project. |
| Investor | Individual or institution that completes KYC and may commit funds to approved projects. |
| Offer | Versioned published project disclosure accepted by an investor before commitment. |
| Commitment | Investor intention/reservation to invest in a specific project and offer version. |
| Allocation | Confirmed assignment of reconciled funds to an investor-project position. |
| Voucher | Controlled accounting document that becomes immutable after posting. |
| Reversal | Corrective accounting workflow for posted vouchers. |
| Distribution | Approved investor entitlement and payment process from locked financial results. |
| Maker-checker | Segregation where the creator of a controlled action cannot finally approve it. |
